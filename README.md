# Markseg - Estratégias de SEO e Conteúdo (Clientes)

Repositório central da MarkSeg para **estratégias de conteúdo SEO + Blog + Redes Sociais** dos clientes.

O objetivo é padronizar: todo cliente recebe um documento com **a mesma estrutura, a mesma metodologia e o mesmo nível de profundidade** do documento de referência (G5 Segurança).

## Estrutura do repositório

```
.
├── README.md                              ← este arquivo
├── modelo/
│   ├── TEMPLATE-Estrategia-SEO.md         ← modelo em branco, com campos a preencher
│   └── BRIEFING-Cliente.md                ← checklist do que coletar de cada novo cliente
└── clientes/
    └── g5-seguranca/
        └── Estrategia-SEO-G5-Seguranca.md ← documento de referência (exemplo preenchido)
```

## Como replicar para um novo cliente

1. **Coletar as informações** do cliente usando o `modelo/BRIEFING-Cliente.md`.
2. **Copiar** o `modelo/TEMPLATE-Estrategia-SEO.md` para `clientes/<nome-do-cliente>/Estrategia-SEO-<Nome>.md`.
3. **Preencher** todos os campos `{{entre chaves}}` e substituir as instruções em `> _itálico_` pelo conteúdo real.
4. Usar o documento do **G5 Segurança** como referência de tom, profundidade e formato.
